# HienaDev Dev Tools

Editor tools for every Unity project (Unity 6+). Everything is under the **Tools** menu.

| Tool | Menu | What it does |
|---|---|---|
| Build All | Tools > Build All (Windows + Web) | Name / version / options in one window, a pre-build check of the usual mistakes (with Fix buttons, run before every build) and quick player settings (icon, cursor, window, web size); builds Windows and Web in one click (it survives the platform switch), zips them as `[Name] v[version] [Platform].zip` in `Build/`, opens them, writes a build report and can publish to itch.io with butler. |
| Perf Doctor | Tools > Perf Doctor (easy profiler) | Records a few seconds of Play mode (or a development build) and says in plain words what takes the time: verdict, CPU or GPU bound, biggest costs, hitches, garbage. |
| Audio Trimmer | Tools > Audio Trimmer, or right-click a sound > Trim Audio | Waveform, select, play/loop, fades, volume, pitch, seamless loops, split into regions; saves a new .wav. Remove background sound (hiss, fan, hum, room noise; learns it from a selection or finds it), cut rumble, quiet the gaps. Type over the name at the top to rename the file; one name for all regions. Random variations, loudness (LUFS), tone, reverb, and a Batch page that does the same to many sounds (into a new folder). The tools you use are open cards, the others small buttons. Echo, stretch without changing the pitch, volume drawn on the wave, matching another sound's tone and loudness, loops found in music. Make page: whooshes, hits, steps, explosions, zaps, blips, pick-ups, risers and wind from nothing. Record page: from the microphone. Layers page: a few sounds on top of each other, with the same tools, linked to Edit, saved as one. Drag the panels' edges to resize them; fades are curves on the waveform you drag; Hear them all in a row plays the original and every variation. A click only moves the red line; Move mode and the small overview move around without cutting. Ten layouts in the Layout dropdown (top right; remembered). Voice effects: 34 ready-made voices (monsters, robots, radios, ghosts...) and 11 effects to mix. Ambience page: a background loop with sounds scattered over it, as an Ambience Player in the scene (never the same twice) or one saved loop. Check page: finds sounds that are too loud, too quiet, crackling, late, silent or bigger than they need to be. Ambience timeline (ruler, colour per group, click to hear, drag to move, Delete mutes). Music parts: splits a song into its calm part and its hits, and a Music Layers player fades the hits in with Intensity. |
| Screenshot | Ctrl+Shift+K, Tools > Screenshot | Game view screenshots (1x / 2x / 4x) into `Screenshots/` next to Assets. |
| Itch Page Kit | Tools > Itch Page Kit | Cover (630x500), 16:9 screenshots, banner, square or any size, from the running game or from an image in the project (fill or fit with bars). GIF maker: images held for a while, GIFs you already have and live recordings, one after another with fades (an image first = a GIF cover). Can hide the game's UI. Saved to `Build/Itch Page`, listed small with a full-size viewer. |
| Web Size Tester | Tools > Web Size Tester | Sets the Game view to real screen sizes (itch.io embeds, laptop, full HD, ultrawide, phones, tablet); "Check every size" takes a picture of each and lists UI cut off by the edges. |
| Play toolbar | Unity's top toolbar (right-click it to show/hide each) | Play from the first scene, game speed slider, restart the scene, frame-rate cap (15/30/60), Game view screenshot, clear saves with a backup (Unity 6.3+; older: Tools > Play Bar). |
| Scene switcher | Top toolbar, left | Every scene in one dropdown: the build's first, then the rest by folder. |
| Jam timer | Top toolbar, right | Countdown to the deadline with reminders (24 h, 6 h, 2 h, 1 h, 30 min, 10 min); the deadline is saved in ProjectSettings so the team shares it. |
| Notes & TODO | Hierarchy: right-click > Add Note or TODO; Notes & TODO tab: "+ In the scene" (Ctrl+Alt+N) | Notes/TODOs pinned to objects or placed anywhere in the scene (saved in the scene or prefab, so git shares them; left out of builds). Shown in the Hierarchy and as sticky cards in the Scene view (hover for the whole note), with checklists of steps, "for who", priority, colour, and "Look" to jump back to the view it was written from. One list of everything, plus project TODOs. |
| Hierarchy icons | automatic | Each object shows its main component's icon (or the icon you picked: right-click > Choose Icon...). Script icons: right-click a component > Choose Script Icon... |
| Folder colours | Project: right-click a folder > Folder Colour / Folder Icon | Saved in ProjectSettings/HienaDevTools.json (shared through git); common folder names get icons by themselves. |
| Find References | Project: right-click an asset > Find References | Every scene, prefab, material and asset that uses it, plus the objects in the open scene pointing at it; "Nothing uses it" when it's safe to delete. |
| Bulk Rename | Tools > Bulk Rename, or right-click > Bulk Rename... | In plain words: give everything one new name (Rock 01, Rock 02...) or change part of the names (swap a word, take off "(1)", cut letters, add words, capitals); see the new names before renaming; Ctrl+Z for objects. |
| Changelog | Tools > Changelog | New / Changed / Fixed / Removed notes per version in CHANGELOG.md (shared through git); "Suggest from what changed" lists the scenes, prefabs, scripts, art and sounds added, changed or removed since the last version (and git commits); Build All's version bump files the notes; copy as an itch.io devlog. |
| Missing Scripts | Tools > Missing Scripts | Objects in the open scenes and prefabs with missing scripts or broken references; click to go there, one button to remove the missing scripts. |
| Scene Gallery | Tools > Scene Gallery, or the toolbar's scenes list | Every scene as a picture (taken when you save it, so the gallery never opens scenes); click to open. |
| Asset Size Watcher | Tools > Asset Size Watcher | Warns when an import is much bigger than it needs to be (4K textures, uncompressed textures or sounds, long sounds unpacked in memory, readable models, huge videos) with one-click fixes; can check the whole project. |
| Auto Fit UI | Tools > Auto Fit UI; right-click a Canvas > Make It Fit Every Screen | Canvas UI that fits any screen, in builds too: scales without cutting anything off, keeps out of phone notches, re-pins each element to its edge or corner (keeping its look), big panels shrink (or grow on upright phones) to fit. One click in the editor (before/after previews on 6 screens), an AutoFitCanvas that fits itself when the game starts, or "Fit every Canvas in the game" for no setup at all. "Always 16:9" switch: the game keeps one shape (16:9, 16:10, 4:3, 21:9, 9:16, 1:1 or any custom size like 2560 x 1080) on every screen with black bars, and the UI stays inside, in Play mode and builds; change it while the game runs with AspectLock.Lock(16, 9) / AspectLock.Unlock() or the "+ Add a screen shape picker" button in the window (a ready-wired dropdown in the selected panel) or the Aspect Lock Control component (hook a Button, Toggle or Dropdown to it, remembers the choice). UI Toolkit: AutoFitDocument. Example scene included. |
| Texture Studio (sample) | Package Manager > HienaDev Dev Tools > Samples > Import, then Tools > Texture Studio; right-click a texture > Texture Studio | Edit a texture as one session: click tools to stack them up (even lighting, make it loop, hide the repeat (same size or bigger), move, colour, dirt and wear, crunch (old-console colours, dither, blocky compression, grain), pixel art, sharpen, blur, resize (crunchy, harsh or smooth), flip/turn), compare before/after with a slider, repeat 1x-3x, then save it with its normal, height and AO/smoothness maps and a ready URP material. Plus Shrink many (presets with undo) and Make a mask map. Originals are never changed. Save asks for a name and puts everything in a folder with that name; right-click a saved material or texture > Texture Studio > Reopen, or use the Library page (everything made in this project). It opens where you left off; Start over empties it. Mix with another puts a second texture on painted parts, patches, cracks or high parts. The saved material can be normal, Never repeats (a shader that hides the repeat on any size of surface; `HienaNoRepeat.hlsl` adds it to your own shaders) or a copy of yours. Stickers puts blood, cracks, stains or your own pictures on a texture. The Decals page makes decals and clicks them onto things in the scene. See-through pictures come out cut out or smooth. Foot keeps a wall's foot (and top) as it is while the rest is made to loop. Glow makes an emission map from paint, colours or brightness. Drag the panels' edges to resize them. 3D preview (or your own model), your own recipes, paint out spots, shared palettes, and tile variations that fit next to each other. Also: Straighten and Remove shadows for photos, Recolour, Match another, Edge wear (uses a model), text as sticker, decal or glow, stickers and glow painted on the 3D model, 16 ways to make a glow map (and a Glow Mover component), a Patterns page (45 ready-made, all adjustable), a Paint page (paint textures on the objects in the scene), random tiles in Never repeats. Decals are children of what they are on. Round 11: drag steps to reorder, "Last step only" compare, Make it loop > Lines (slats, stripes) and "Even out the light first", edge wear on the texture's own edges or its sides or only where painted, stickers picked and changed with a frame, decals bend round corners and can be changed after placing (click one), a placing panel in the Scene view, paint meets at corners and new paint sits on top. Round 12: sticker modes (Place new / Pick and change, Tab), decal sheets (4, 6, 9 or your own grid; a random one per click), paint taken from an object in the scene, Pixel art with palettes, dither, outlines and cleaning. |
| Building Builder (sample) | Package Manager > HienaDev Dev Tools > Samples > Import (Texture Studio is imported with it), then Tools > Building Builder | Build floor by floor on a grid, inside its own window or in the Scene view: rooms, floors (each with its own height), walls (straight or curved, with skirting, crown and wainscot), doors, windows and arches with frames, glass and doors that open, stairs (straight, turning, U, ramp, spiral, ladder) that open the floor above, raised areas, holes, lift shafts, balconies, tunnels, columns, beams, roofs (flat, parapet, gable, hip, shed) and your own parts. Railings with posts, bars, a panel or glass (how many, square or round, your own post and handrail models), on the sides you pick (none along a wall), per stair or floor or for the whole building. Each door or window can take your own model; any built piece (steps, step tops, doors, windows, glass, columns, beams, gutters, ladder rungs, roofs) can be swapped for your own model or material. One roof over joined rooms (wings meet in valleys), attics with gable windows, round and any-shape rooms (corners you add, move and remove, walls follow), broken holes, open or cupboard stairs, double doors, balcony posts. Move/turn/scale handles, a right-click menu, previews of what you place, Esc or right-click cancels, keys sheet (F1), lighting presets, hide the roof or outside walls, shuffle rooms, plans of every floor (copied to paste), NavMesh up stairs and through doors. Paint everything, Texture Studio materials included. Walk mode, a person for scale, measurements, room stamps and styles, floor plan PNG, NavMesh and prefab export (with room connectors). PSX look (HienaDev/PSX Lit: wobble, swimming textures, colour steps). |
| Cinematic Editor (sample) | Package Manager > HienaDev Dev Tools > Samples > Import | A full cutscene editor (shots, camera moves, looks, pop-ups, overlays, audio, events) with a live viewer. Optional: only added when you import the sample. Window > Cinematic Editor. |
| Selection history | Toolbar ◀ ▶ and the clock list, Alt+Left / Alt+Right | Back and forward through what you selected, like a browser. |
| Favourites | Tools > Favourites, toolbar ★, right-click > Add to Favourites | Pinned assets and objects: click to select, double-click to open; per person (UserSettings). |

Switches for all of these: Edit > Project Settings > HienaDev Dev Tools.

## Add it to a project

Package Manager > **+** > **Install package from git URL**, then paste `https://github.com/HienaDev/HienaDevTools.git`.
Or add this line to `Packages/manifest.json`:

```
"com.hienadev.devtools": "https://github.com/HienaDev/HienaDevTools.git",
```

To update: Package Manager > HienaDev Dev Tools > **Update**.
